## UI-002 プリセット操作完了ポップアップ

- 状態: 承認済み・公開済み（2026-08-12）
- 受付日: 2026-08-12

## UI-003 プリセット読み込み時の画面位置維持

- 状態: 承認済み・公開済み（2026-08-12）
- 受付日: 2026-08-12

### 要望

### 原因

- 現在はプリセット読み込み後にページ全体を再読み込みしているため、スクロール位置が上部へ戻る。

## DESIGN-001 試作段階の保存データ互換性

- 状態: 承認済み・公開済み（2026-08-12）
- 受付日: 2026-08-12

### 方針

- 本ツールは試作段階のため、既存プリセットとの後方互換性を原則として必須としない。
- 新しい選択項目の追加、既存選択肢の文言変更、既存選択肢の削除が発生した場合、ユーザーから個別の引き継ぎ相談がない限り、既存プリセットを引き継がない。
- 新しいデータ構造と整合しない既存プリセットは、無効化または削除してよい。
- 必要であれば前回入力値も新しい初期値へリセットしてよい。
- ユーザーから引き継ぎの相談があった場合だけ、対象版の差分を確認して移行方法を別途提案する。

### 推奨実装

- 前回入力値とプリセットの保存キーを新しい版へ更新する。
- 旧形式の値を新形式へ推測変換せず、新しい初期値から開始する。
- 旧保存キーは初回起動時に削除するか、参照対象外として無効化する。
- 保存データの版を明示し、以後の構造変更を判別できるようにする。
- 選択肢または項目構造を変更する実装計画では、プリセット版の更新要否を毎回確認する。

### 影響

- 公開更新後、既存の名前付きプリセットと前回入力値が利用できなくなる可能性がある。
- 試作段階では互換処理を持たないため、衣装の条件分岐とプリセット処理を単純かつ検証しやすくできる。

## OUTFIT-001 衣装タイプ・構成・デザインの3段階選択

- 状態: 承認済み・公開済み（2026-08-12）
- 受付日: 2026-08-12

### 参照JSONの扱い

- 提供されたJSONは、4系統の衣装に関する候補情報を抽出するためだけに利用する。
- JSONのUIラベル、指示文テンプレート、内部属性表現、データ構造をそのままアプリへ採用しない。
- 抽出後の選択肢名称と指示文規則は、このPWA用に別途設計する。

### 3段階の分類

1. 衣装タイプ
   - 初期値なし
   - ステージ衣装
   - 私服・その他衣装
2. 衣装構成
   - 初期値なし
   - 上下分離
   - 上下一体
3. 衣装デザイン
   - 選択中の衣装タイプと衣装構成の組み合わせに対応する8種類

### 上下分離時の表示項目

1. トップスデザイン
2. トップスの色
3. ボトムスデザイン
4. ボトムスの色
5. 衣装装飾

### 上下一体時の表示項目

1. 衣装デザイン
2. 衣装の色
3. 衣装装飾

### 衣装装飾の選択肢

1. 無し
2. 内容は衣装に合わせておまかせ、装飾量は控えめ
3. 内容は衣装に合わせておまかせ、装飾量は華美

初期値は、衣装タイプ・衣装構成にかかわらず次とする。

`内容は衣装に合わせておまかせ、装飾量は控えめ`

### 動作方針

- 衣装タイプまたは衣装構成の変更時、ページを再読み込みせず対応項目と選択肢をその場で更新する。
- 上下分離から上下一体へ変更した場合は、トップス・ボトムス項目を衣装デザイン・衣装色へ置き換える。
- 上下一体から上下分離へ変更した場合は、衣装デザイン・衣装色をトップス・ボトムスの各項目へ置き換える。
- 衣装装飾は両構成で表示する。
- 上下分離ではトップス8種類とボトムス8種類を独立して選択し、1系統あたり最大64通りの組み合わせを可能にする。
- 現在の「衣装の基調カラー」は廃止する。
- 色の初期値は、上下分離ではトップスを「ホワイト」、ボトムスを「チャコールグレー」とし、上下一体では衣装を「ホワイト」とする。
- 指示文には、実際の選択値を使用して次の2行を衣装詳細より前へ出力する。
  - `衣装タイプは［選択値］`
  - `衣装構成は［選択値］`
- 保存データは新しい版へ更新し、ユーザーから移行相談がない限り旧プリセットを引き継がない。

### 確定済み事項

1. 上下分離は、トップス8種類とボトムス8種類を独立して選択する。
2. 衣装装飾の初期値は「内容は衣装に合わせておまかせ、装飾量は控えめ」とする。
3. 現在の「衣装の基調カラー」は廃止する。
4. 指示文へ「衣装タイプ」と「衣装構成」を独立した2行として出力する。
5. 衣装タイプは初期値なしとする。
6. 衣装構成は初期値なしとする。
7. 色の初期値は、上下分離ではトップス「ホワイト」・ボトムス「チャコールグレー」、上下一体では衣装「ホワイト」とする。
8. 衣装装飾で「無し」を選択した場合も、指示文へ `衣装装飾は無し` と明示的に出力する。

### 指示文の出力例

上下分離:

```text
衣装タイプはステージ衣装
衣装構成は上下分離
トップスはホワイトの長袖・スタンドカラー・ウエスト丈 ショートジャケット
ボトムスはチャコールグレーのハイウエスト・ミニ丈 フレアスカート
衣装装飾の内容は衣装に合わせておまかせ、装飾量は控えめ
```

上下一体:

```text
衣装タイプはステージ衣装
衣装構成は上下一体
衣装はホワイトの半袖・スクエアネック・ハイウエスト・ウエスト丈上身頃・ミニ丈 フィット＆フレアドレス
衣装装飾の内容は衣装に合わせておまかせ、装飾量は控えめ
```

装飾選択が「無し」の場合は `衣装装飾は無し` と出力し、それ以外は `衣装装飾の内容は［内容］、装飾量は［量］` と自然な日本語で出力する。
