# 選択項目・選択肢カタログ

開発候補版はPWA 5.0.0。完全な閲覧用一覧は [`options.html`](../options.html) で確認する。公開後はGitHub Pagesでも検索、折りたたみ、初期値表示、55色のカラーチップを利用できる。

この文書はGitHub上で構成を素早く把握するための索引であり、選択肢の正本は `src/catalog.js` と `src/outfits.js` である。

## 固定出力

`ユーザー指示`、`画像の新規生成`、`フォトリアル`、`架空の20代の成人日本人女性`、`美人`、`脚の長いモデル体型`

## 衣装

- 衣装タイプ: ステージ衣装、私服・その他衣装（初期値なし）
- 衣装構成: 上下分離、上下一体（初期値なし）
- 上下分離: 系統ごとのトップスとボトムスを独立選択
- 上下一体: 系統ごとの一体型衣装を選択
- アウター: 11候補（無しを含む）、両構成共通
- 靴: 17候補（裸足を含む）、全衣装共通
- 衣装装飾: 無し、衣装に合わせておまかせ・控えめ、衣装に合わせておまかせ・華美
- 色: 共通55色

## 撮影設定

## 更新方法

選択肢を変更するときは正本のコードと自動試験を更新する。閲覧ページは正本を直接読み込むため自動反映される。このMarkdown索引は項目構造、件数、初期値が変わった場合に更新する。
