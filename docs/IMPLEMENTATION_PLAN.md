# 実装計画書

## 1. 目標

1. GitHub Pages上に完全クライアント処理型PWA「神は7日で世界を作った」を構築し、AI人物生成に有効な選択肢を拡充して指示文生成を検証する。
2. 生成した基準指示文を画像生成GPTへ投入し、Codexとユーザーが相談しながら調整し、同一条件3回の画像品質チェックでユーザーの明示的な「合格」を得る。
3. 合格後、旧・指示文生成GPTを非公開化して到達不能を確認し、ユーザーの最終承認後に完全削除する。

## 2. PWAの仕様

- 主端末: iPhone 16。393×852 CSS px相当の縦表示、safe area、44px以上の操作領域、16px以上の入力文字、横スクロールなしを事前検証する。
- 実機確認: Chromiumの端末エミュレーションはレイアウト確認に限定し、iPhone 16のSafariでホーム画面追加、入力、色選択、コピー、再読込、オフライン起動を確認する。
- 処理: ブラウザ内だけで完結し、API、DB、分析、広告、外部フォントを使わない。前回値と名前付きプリセットのみlocalStorageへ保存する。
- UI: 一般項目はプルダウン。色はカラーチップと名前を組み合わせた選択パネル。自由記述と任意HEX入力は設けない。
- 選択肢: 具体的で視覚差があり、画像モデルが解釈しやすく、他項目と組み合わせやすい語句を優先する。
- 任意項目: 表情、ポーズ、構図、背景、照明。未選択なら出力せず、選択時はこの順で末尾へ追記する。
- 公開: ローカル自動試験の成功を確認してから `main` へ反映し、GitHub Pagesのブランチ配信で公開する。

## 3. 指示文検証

- 基準設定の出力が承認済み13行と完全一致することを自動試験する。
- 必須初期値がカタログ内に存在すること、色名称が定義済みチップと一対一であること、重複がないことを試験する。
- 任意項目の省略と追記順、衣装色と衣類名の合成、外部通信要素の不在、PWA主要資産を試験する。
- 公開後にコピー結果、プリセット、再読込保持、オフライン起動を確認する。

## 4. 画像生成GPTの調整と品質合格

### 優先順位

1. 画像生成GPTのInstructions
2. 画像生成GPTのKnowledge
3. InstructionsとKnowledge間の競合・役割分担
4. PWAの表現力または出力語句が原因の場合だけ、PWAの選択肢、出力語句、項目構造、指示文規則

調整前に、画像生成GPTの名称、説明、モデル、Instructions、Knowledge、機能、会話のきっかけ、共有状態を読み取り確認する。InstructionsとKnowledge本文は公開リポジトリへ保存せず、非公開領域にバックアップする。公開ログには版、ハッシュ、変更目的、要約だけを記載する。

### Codexとユーザーの共同調整

1. PWAで基準指示文を生成する。
2. 画像生成GPTの独立した新規会話へ投入する。
3. ユーザーが画像を目視し、気になる点や期待との差を伝える。
4. Codexが差異を人物、人体、衣装、色、髪、瞳、構図、フォトリアル性に整理する。
5. Codexが原因をInstructions、Knowledge、両者の競合、PWAのいずれかに診断する。
6. Codexが修正候補、期待効果、副作用、影響範囲を提示する。
7. ユーザー承認後、原則として画像生成GPTのInstructionsまたはKnowledgeを一変更単位ずつ更新する。
8. PWAが原因の場合だけ、選択肢、出力語句、項目構造または指示文規則を更新する。
9. GPT変更時は設定と共有状態を再確認し、PWA変更時は自動試験と再公開を行う。
10. 独立した新規会話で再生成し、ユーザーが納得するまで反復する。

### 合格条件

安定した同一指示文を、同一PWA版・同一GPT設定版で、履歴のない独立した新規会話3件へ各1回投入する。3画像をユーザーが目視し、最終的に明示的な「合格」を宣言した時点で完了とする。1件でも不合格なら調整サイクルへ戻る。

## 5. 旧GPTの停止と削除

1. PWA自動試験、Pages公開、iPhone実機確認、画像生成GPT調整、3画像合格を完了する。
2. 旧・指示文生成GPTを非公開化または共有停止する。
3. 旧リンクから利用できないことを確認してユーザーへ報告する。
4. 永久削除についてユーザーの明示的な最終承認を得る。
5. 承認後に完全削除し、一覧からの消失と旧リンクの無効化を確認する。

既存の会話履歴や生成画像は削除対象に含めない。

## 6. 記録

- `docs/IMAGE_QUALITY_LOG.md`: ケースID、PWA版、GPT設定版、ハッシュ、指示文、ユーザー指摘、診断、承認済み変更要約、再生成結果、判定。非公開Instructions/Knowledge本文は記録しない。
- `docs/RETIREMENT_LOG.md`: 停止時刻、到達不能確認、削除承認、削除時刻、最終確認。

## 7. 承認ゲート

- 画像生成GPTの設定変更は、変更案と影響を提示してユーザー承認後に行う。
- 画像品質合格はユーザーの目視と明示的な「合格」に限る。
- 旧GPTの永久削除は、非公開化と到達不能確認後に別途明示承認を得てから行う。
