# 神は7日で世界を作った

架空の20代の成人日本人女性を対象に、人物画像生成用の日本語指示文を選択式で作成する完全クライアント処理型PWAです。単一画面内でフォトリアル人物画像用とアニメ人物イラスト用を切り替え、画風そのものは出力先の画像生成GPTが決定します。

## 特徴

- 通常項目はプルダウン、色は名称付きカラーチップから選択
- 髪色・瞳・衣装色で同じ順序の共通110色を使用
- 髪型26種類と前髪9種類を独立して選択
- 衣装タイプと衣装構成に応じて4系統の衣装候補を切り替え、アウターと靴も独立選択
- フォトリアル用は表情4種類、ポーズ12種類、構図4種類、カメラ高さ3種類、撮影方向4種類、背景19種類、照明16種類を独立選択
- アニメ用は目の形6種類、表情16種類、ポーズ45種類、構図7種類、カメラアングル7種類、撮影方向4種類、背景19種類、照明32種類を独立選択
- 画面下部の切替アイコンから、ページ再読込なしで写真モードとアニメモードを切り替え
- 生成指示文は改行を含まない1行の文章として出力
- 前回値と名前付きプリセットを端末内の `localStorage` にのみ保存
- Service Workerによるオフライン利用
- API、データベース、アクセス解析、広告、外部フォントなし
- iPhone 16を主対象とするレスポンシブUI

## 開発

```sh
npm test
npm run serve
```

iPhone実機確認時は、同一Wi-Fi内のPCで `npm run serve:lan` を実行し、PCのLAN IPの4175番へアクセスします。

公開版はGitHub Pagesから配信します。実機Safari確認はChromiumのモバイル表示確認とは別に実施します。

公開URL: https://d9s472jjcr-spec.github.io/7days/

## 非公開情報の扱い

画像生成カスタムGPTのInstructionsやKnowledge本文は、この公開リポジトリへ保存しません。変更履歴にはバージョン、ハッシュ、目的、要約だけを記録します。

## 保存データ

項目構造や選択肢を変更した版では、個別の移行要望がない限り旧プリセットを引き継ぎません。写真版は公開版6.2.0の保存形式v8を維持します。アニメ版は専用の保存形式v1を使い、写真版の前回値・プリセットを読み書き・削除しません。
