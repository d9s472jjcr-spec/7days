# 神は7日で世界を作った

架空の20代の成人日本人女性を対象に、人物画像生成用の日本語指示文を選択式で作成する完全クライアント処理型PWAです。写真・アニメで共用できる画風非依存の指示文を単一画面で生成し、画風そのものは出力先の画像生成GPTが決定します。

> 開発状態（2026-08-20）: PWA 9.0.0のローカル実装、自動試験32件、393×852相当のブラウザー操作確認まで完了しています。コミット、Pull Request、GitHubへのマージ、GitHub Pages公開、iPhone 16実機Safari確認は未実施です。現行公開版は8.0.0です。

## 特徴

- 通常項目はプルダウン、色は名称付きカラーチップから選択
- 髪色・瞳・衣装色で同じ順序の共通110色を使用
- 9.0.0では髪型、髪色、前髪を画面最上部へ配置
- 人物の特徴60種類を追加し、初期値は「クール」
- 身長、バスト、ウエスト、ヒップを1cm刻みのスライダーで指定
- 身長変更時に連動中のバスト、ウエスト、ヒップだけを再計算し、手動変更した項目は個別に連動解除
- バスト、ウエスト、ヒップの数値を定型表現へ変換し、推定カップをUIと生成文へ表示
- 衣装タイプと衣装構成に応じて4系統の衣装候補を切り替え、アウター、上下の下着、靴も独立選択
- 目の形6種類、目の表現18種類、特殊な目10種類、口の表現24種類を独立選択
- UIの分類名を読み上げず、人物の外見と実際の着用内容だけを簡潔で自然な1行の文章として出力
- ポーズ、構図、カメラ、撮影方向、背景、照明、画像比率、接地影、撮影用禁止事項は9.0.0のUIと生成文から削除
- 前回値だけを端末内の `localStorage` に自動保存し、名前付きプリセット機能は9.0.0で削除
- Service Workerによるオフライン利用
- API、データベース、アクセス解析、広告、外部フォントなし
- iPhone 16を主対象とするレスポンシブUI

## 開発

```sh
npm test
npm run serve
```

iPhone実機確認時は、同一Wi-Fi内のPCで `npm run serve:lan` を実行し、PCのLAN IPの4175番へアクセスします。

公開版はGitHub Pagesから配信します。実機Safari確認はChromiumのモバイル表示確認とは別に実施します。

公開URL: https://d9s472jjcr-spec.github.io/7days/

## 保守・引き継ぎ

第三者が保守を開始する場合は、次の順で確認してください。

1. [引き継ぎガイド](docs/HANDOFF.md)
2. [PWA仕様書](docs/PWA_SPECIFICATION.md)
3. [運用・公開手順書](docs/OPERATIONS_RUNBOOK.md)
4. [画像生成GPT運用手順書](docs/GPT_OPERATIONS.md)

選択肢、初期値、UI表示名、出力語句、色チップの正本は、`src/` 内の選択肢データと `tests/` 内の自動試験です。別形式の選択肢台帳は運用しません。

現行公開版はPWA 8.0.0です。ローカル作業版9.0.0は自動試験とブラウザー操作確認に合格していますが、ユーザーの別途承認を得るまでコミット、Pull Request作成、マージ、公開を行いません。検証履歴と9.0.0の作業状態は `docs/` 内の計画書、仕様書、改善要望記録、運用文書を参照してください。

## 非公開情報の扱い

画像生成カスタムGPTのInstructionsやKnowledge本文は、この公開リポジトリへ保存しません。変更履歴にはバージョン、ハッシュ、目的、要約だけを記録します。

## 保存データ

現行公開版8.0.0は統合保存形式v1を使用します。ローカル作業版9.0.0は `7days:unified:last-values:v2` とスキーマ版 `2` を使用し、前回値と寸法の連動状態だけを自動保存します。旧統合v1を優先し、存在しない場合だけ旧写真v8から初回移行します。名前付きプリセットは読み書きせず、既存プリセットの保存データも削除しません。

## 選択肢管理

選択肢、初期値、UI表示名、出力語句、色チップは `src/` と `tests/` を正本とします。Excelを含む別形式の選択肢台帳は利用、更新、照合しません。既存ファイルを削除する場合は別途承認が必要です。
